## 🎵 About The Project

**Spotify Web Control** is a lightweight web-based project designed to provide a simple interface for controlling Spotify through a browser.

The project focuses on creating a clean and easy-to-use web experience for interacting with Spotify playback and controls.

---

## ✨ Features

* 🎵 Spotify Web Control
* ▶️ Play / Resume Music
* ⏸️ Pause Playback
* ⏭️ Skip to Next Track
* ⏮️ Previous Track
* 🔊 Playback Controls
* 🎧 Music-focused Interface
* 🌐 Browser-Based Experience
* 📱 Responsive Design
* ⚡ Lightweight & Fast
